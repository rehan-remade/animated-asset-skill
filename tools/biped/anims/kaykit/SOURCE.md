# KayKit Character Pack: Adventurers (CC0)

`Knight.glb` is copied unmodified from
https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0
(`addons/kaykit_character_pack_adventures/Characters/gltf/Knight.glb`), by Kay Lousberg,
released under CC0 1.0 (see LICENSE.txt). It is used here only as the *animation source*:
its 41-bone rig carries 76 clips (melee 1H/2H/dual, spellcasting, ranged, locomotion,
interact/pick-up, hits, deaths, emotes). The retargeter reads the clips off this rig and
writes them onto the voxel biped; none of the Knight's meshes end up in your export.

The same rig is shared by every KayKit character, and the itch.io-only
"KayKit Character Animations" pack (also CC0) adds dedicated Pickaxe / Chop / tool clips
that drop in through the same bone map.
